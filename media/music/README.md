# 🎵 media/music — โฟลเดอร์เพลงของหุ่น

วาง**ไฟล์เพลงที่คุณได้มาถูกต้องตามกฎหมาย**ไว้ในโฟลเดอร์นี้ (เช่น ซื้อ/ดาวน์โหลดจากผู้ให้บริการที่มีลิขสิทธิ์)

> ⚠️ โปรเจกต์นี้**ไม่แจกไฟล์เพลง** เพราะเพลงส่วนใหญ่มีลิขสิทธิ์
> (เช่น "เขาคือพี่แอ็ด" ของคาราบาว — ต้องใช้ไฟล์ของคุณเอง)

## รูปแบบไฟล์ที่รองรับ
`.mp3` `.wav` `.m4a` `.ogg` `.flac` `.aac` `.wma`

## ตั้งชื่อไฟล์
หุ่นจะค้นหาแบบ fuzzy (ไม่สนช่องว่าง/ขีด/ตัวพิมพ์) — ตั้งชื่อให้มีคำที่คนพูดถึง เช่น

```
เขาคือพี่แอ็ด - คาราบาว.mp3
khao khue phi aed - carabao.mp3
เพลงช้าง.mp3
happy birthday.mp3
```

## ใช้งาน

ผ่านการพูดกับหุ่น (tool calling) — หุ่นจะเรียก `play_music` เองเมื่อคุณพูดว่า
"เปิดเพลงเขาคือพี่แอ็ดของคาราบาว"

หรือทดสอบตรง ๆ:

```powershell
.venv\Scripts\python.exe -c "from src import music; print(music.list_tracks()); print(music.play('เขาคือพี่แอ็ด'))"
```

## หมายเหตุ
- ใช้ `ffplay` (มากับ ffmpeg) → หยุดกลางเพลงได้ (`stop_music`)
- ถ้าไม่มี `ffplay` จะใช้ `playsound3` (หยุดไม่ได้)
- หุ่นจะ**เต้น**ระหว่างเพลงเล่น (ปิดได้ด้วยพารามิเตอร์ `dance: false`)
