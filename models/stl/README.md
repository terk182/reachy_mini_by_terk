# 📁 models/stl/ — ไฟล์ STL สำหรับ MuJoCo simulation

วางไฟล์ `.stl` ของชิ้นส่วนที่คุณจะ 3D print ลงในโฟลเดอร์นี้ แล้วเปิดใช้งานใน
`config/robot_config.py`:

```python
"meshes": {
    "enabled": True,
    "dir": "models/stl",
    ...
}
```

จากนั้นรัน `python scripts/run_simulation.py` — MuJoCo จะแสดงชิ้นส่วนจริงของคุณ
(ถ้าไม่มีไฟล์ จะใช้รูปทรงพื้นฐานแทนอัตโนมัติ)

> 💡 **ไม่มีไฟล์ STL?** รัน `python scripts/generate_sample_stls.py`
> เพื่อสร้างชิ้นส่วนตัวอย่าง (ฐาน, จาน 6 เหลี่ยม, ขา, หัว, เสาอากาศ + แขนหมุน/ก้านต่อ)
> ไว้ดูเป็นตัวอย่าง แล้วค่อยแทนที่ด้วยชิ้นส่วนจาก CAD จริงของคุณ (ใช้ชื่อไฟล์เดิม)

## 📐 ข้อกำหนด coordinate frame ของแต่ละชิ้น

หน่วยของ STL = **มิลลิเมตร** (mm) — โปรแกรม scale เป็นเมตรให้อัตโนมัติ
แกนของ MuJoCo: **+X ขวา, +Y หน้า, +Z ขึ้น**

| ไฟล์ | ชิ้นส่วน | จุด origin (0,0,0) ควรอยู่ที่ | ทิศทาง |
|------|---------|------------------------------|--------|
| `base.stl` | ฐาน | กึ่งกลางฐาน | +Z ขึ้น, แบนบนระนาบ XY |
| `lower_plate.stl` | จานล่าง Stewart | จุดศูนย์กลางจาน | แบนบนระนาบ XY, +Z ขึ้น |
| `leg.stl` | ขา (ใช้ซ้ำ 6 ขา) | จุดต่อด้านล่าง | ยาวไปทาง **+Z** ความยาว ≈ `leg_home` (~80 mm) |
| `top_plate.stl` | จานบน | จุดศูนย์กลางจาน | แบนบนระนาบ XY, +Z ขึ้น |
| `head.stl` | หัว | จุดศูนย์กลางหัว | ด้านหน้า (กล้อง) ชี้ **+Y** |
| `antenna.stl` | เสาอากาศ (ใช้ซ้ำ 2) | จุดต่อกับหัว | ยาวไปทาง **+Y** |

> 📌 **ชิ้นส่วนกลไก (print จริง) ที่สร้างเพิ่มจาก sample generator**
> ไฟล์ 2 ชิ้นนี้**ไม่ได้ใช้ใน sim** (sim ใช้ `leg.stl` แทนก้าน) แต่เป็นชิ้นส่วนที่ต้อง
> print/ซื้อจริงสำหรับกลไก crank-rod:
>
> | ไฟล์ | ชิ้นส่วน | ขนาด |
> |------|---------|------|
> | `crank_arm.stl` | แขนหมุน (ยึดเพลา servo) | ยาว 40 mm + ดุมกลาง Ø14 |
> | `rod.stl` | ก้านต่อ (หัวบอล 2 ข้าง) | ยาว 85 mm, Ø6, หัวบอล Ø10 |
>
> กลไก: มอเตอร์หมุนแขน (`arm_len=40`) → ดึงก้าน (`rod_len=85`) → ขยับจานบน

> ⚠️ ถ้าไฟล์ STL ของคุณ origin/ทิศไม่ตรงตามนี้ ไม่ต้องแก้ไฟล์! ใช้ `pos` และ `quat`
> ใน `config/robot_config.py` เพื่อปรับตำแหน่ง/หมุนได้:
>
> ```python
> "parts": {
>     "head": {
>         "file": "head.stl",
>         "pos": [0.0, 0.0, 5.0],        # เลื่อน +Z อีก 5 mm
>         "quat": [0.7071, 0.7071, 0, 0], # หมุน 90° รอบ X (w,x,y,z)
>     },
> }
> ```

## 🛠️ เคล็ดลับ

- **ขา 1 ไฟล์ ใช้ซ้ำ 6 ขา** — ขาทุกข้างหมุนโดยอัตโนมัติตามตำแหน่งบนจาน
- **export จาก CAD** (Fusion/FreeCAD/Onshape): export แบบ *STL (Binary)*
  หน่วย mm จะดีที่สุด
- **ไฟล์ใหญ่เกิน?** ลองลด polygon (decimate) — simulation ไม่ต้องละเอียดมาก
- ทดสอบว่าไฟล์โหลดได้: รัน `python scripts/self_test.py` (มี test โหลด STL ให้)
