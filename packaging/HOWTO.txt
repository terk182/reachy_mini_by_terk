# ReachyAssistant — วิธีใช้ (สำหรับผู้รับไฟล์)

น้องรีชชี่ หุ่น Reachy Mini — แชทคุยได้ + ดูภาพจากกล้อง

## เริ่มใช้

1. แตกไฟล์ zip ไว้ที่ไหนก็ได้ (เช่น D:\ReachyAssistant)
2. ดับเบิลคลิก **ReachyAssistant.exe**
3. หน้าต่างจะเปิด: ซ้าย = กล้อง · ขวา = แชท · ล่าง = แถบสถานะ
   - กด **เปิดกล้อง** เพื่อดูภาพ + กรอบใบหน้า
   - พิมพ์ข้อความแล้วกด **ส่ง** หรือ Enter เพื่อคุยกับหุ่น
   - กด **🎤 พูด** เพื่อพูดใส่ไมค์แทนการพิมพ์
   - ปุ่ม 🔄 สแกนใหม่ — กดหลังเสียบ/ถอดกล้องหรือไมค์

> ⚠️ ครั้งแรก Windows อาจขึ้น "Windows protected your PC" → กด **More info → Run anyway**
> (แอปนี้ไม่ได้เซ็นดิจิทัล — ปกติของโปรแกรมที่ build เอง)

## ตั้งค่าครั้งแรก (สำคัญ)

แอปต้องต่อ LLM/STT server — แก้ไฟล์นี้:

```
ReachyAssistant\_internal\config\local_config.json
```

```json
{
  "llm": { "url": "http://<เครื่องเซิร์ฟเวอร์>:11435", "model": "gemma4:e4b", "api_key": "<คีย์>" },
  "stt": { "stt_url": "http://<เครื่องเซิร์ฟเวอร์>:8000", "api_key": "<คีย์>" }
}
```

- ไม่มีเซิร์ฟเวอร์? แชทจะตอบไม่ได้ (กล้องยังใช้ได้)
- ไมค์: เลือกจาก dropdown ในแอปได้เลย — ค่าจะถูกจำอัตโนมัติในไฟล์เดียวกัน

## ใช้กับหุ่นจริง (ถ้ามี)

เสียบ USB-TTL ของหุ่น แล้วเปิดแอปด้วย:

```
ReachyAssistant.exe --hardware
```

(ถ้าไม่ใส่ --hardware จะเป็นโหมดจำลอง — ไม่ขยับหุ่นจริง แต่คุย/พูดได้)

## มีอะไรบ้าง / ไม่มีอะไร

✅ แชทกับ LLM + หุ่นพูด (TTS) + ขยับตามอารมณ์
✅ กล้อง + ตรวจจับใบหน้า (YuNet) + เลือกกล้อง/ไมค์
✅ สั่งท่าทางด้วยข้อความ เช่น "เต้นให้ดูหน่อย" "โบกมือ" (โหมดหุ่นจริง)
❌ ไม่มีหน้าต่างหุ่น 3D (MuJoCo) — ตัดออกเพื่อให้ไฟล์เล็กลง
❌ ไม่มีระบบฟังเสียงในเครื่อง (whisper) — ใช้ STT server ผ่านเน็ตเท่านั้น

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|-------|--------|
| เปิดแล้วปิดทันที / ขึ้น error | เปิดผ่าน PowerShell เพื่อดูข้อความ: `.\ReachyAssistant.exe` |
| กล้องไม่ขึ้น | กด 🔄 สแกนใหม่ · เช็คว่ากล้องไม่ถูกโปรแกรมอื่นใช้อยู่ |
| แชทไม่ตอบ | เช็ค `local_config.json` (URL/คีย์) และเน็ต — สถานะจะขึ้น "กำลังคิด..." ค้างถ้าเน็ตช้า |
| ได้ยินเสียงหุ่นช้า/ไม่พูด | ปิด-เปิด checkbox "พูดตอบ (TTS)" · ตอนแชทครั้งแรกอาจช้า (โหลดเสียง) |
