# อัปเกรด STT เป็นโมเดลภาษาไทยโดยเฉพาะ (Typhoon Whisper)

> วันที่: 2026-09-16 · ทำบน **เครื่อง GPU** · เป้าหมาย: ถอดเสียงไทยตรงขึ้น (แก้ปัญหา "แปลไม่ตรงกับที่พูด")

---

## ทำไมต้องเปลี่ยนโมเดล

ผลทดลองกับไฟล์เสียงจริงของเรา:

| การทดลอง | ผล |
|----------|-----|
| ตัดเงียบหัวท้าย + กรองความถี่ต่ำ + ปรับระดับเสียง (ฝั่งหุ่น) | ❌ คำเพี้ยนเท่าเดิม — ไม่ช่วย |
| โมเดล `large-v3` ปกติ | เพี้ยนคำเชื่อมเสียงต่อเนื่อง เช่น "หันหน้าตามมา" → "หัดหน้าช่อมา" |

`large-v3` เป็นโมเดลกลาง ๆ ภาษาอังกฤษเป็นหลัก → โมเดลที่ **เทรนภาษาไทยโดยเฉพาะ** ให้ผลดีกว่าชัดเจน

**ตัวเลือก (เรียงตามแนะนำ):**

| โมเดล | ขนาด | จุดเด่น |
|-------|------|---------|
| `typhoon-ai/typhoon-whisper-turbo` | 0.8B | เบา เร็ว คุณภาพไทยดี (แนะนำเริ่มจากตัวนี้) |
| `typhoon-ai/typhoon-whisper-large-v3` | 2B | คุณภาพสูงสุด (ช้ากว่า ~2-3 เท่า) |
| `biodatlab/whisper-th-large-v3` | 2B | ทางเลือกสำรอง (มหิดล) |

> typhoon-whisper = โมเดล ASR ภาษาไทยจาก SCB 10X (ดู: huggingface.co/typhoon-ai)

---

## ขั้นตอนที่ 0 — deploy hotwords ก่อน (5 นาที)

ทำตาม `docs/stt_server_update.md` ก่อน (จะได้ชื่อ "รีชชี่" ถูกด้วย)

---

## ขั้นตอนที่ 1 — ติดตั้งเครื่องมือแปลงโมเดล (บนเครื่อง GPU)

faster-whisper ใช้รูปแบบ **CTranslate2** ต้องแปลงจาก HuggingFace ก่อน:

```powershell
# ใน venv ที่รัน STT server อยู่
pip install "transformers>=4.40" torch --index-url https://download.pytorch.org/whl/cpu
# (torch CPU ก็พอสำหรับการแปลงอย่างเดียว ไม่ต้อง CUDA)
```

> ถ้าเครื่องมี PyTorch CUDA อยู่แล้วก็ใช้ตัวเดิมได้เลย

## ขั้นตอนที่ 2 — แปลงโมเดลเป็น CTranslate2

```powershell
# ดาวน์โหลด + แปลง (ใช้เวลา 5-15 นาที ขึ้นกับการเชื่อมต่อ)
ct2-transformers-converter --model typhoon-ai/typhoon-whisper-turbo `
    --output_dir D:\models\typhoon-whisper-turbo-ct2 --quantization float16
```

ไฟล์จะอยู่ที่ `D:\models\typhoon-whisper-turbo-ct2\` (ประมาณ 1-2 GB)

## ขั้นตอนที่ 3 — รันเซิร์ฟเวอร์ตัวใหม่คู่กัน (ทดสอบก่อนสลับ)

```powershell
# ตัวใหม่: พอร์ต 8001 ชี้โมเดลไทย
$env:STT_PORT = "8001"
$env:STT_MODEL = "D:\models\typhoon-whisper-turbo-ct2"
python stt_server.py
```

รอจนขึ้น `[STT] พร้อม model=... device=cuda`

## ขั้นตอนที่ 4 — เทียบผลกับโมเดลเดิม (ใช้ไฟล์เสียงจริง)

**บนเครื่องหุ่น** (หรือเครื่อง GPU ก็ได้ ถ้ามีไฟล์ใน `cache/stt_debug`):

```powershell
.venv\Scripts\python.exe server\compare_stt.py --dir cache\stt_debug `
    --a http://<GPU_SERVER>:8000 --b http://<GPU_SERVER>:8001 --key <API_KEY> --last 15
```

*(ถ้าพอร์ต 8001 ยังไม่ forward ออกอินเทอร์เน็ต ให้รันบนเครื่อง GPU ด้วย 127.0.0.1 แทน)*

อ่านผลทีละคลิป: ฝั่งไหนถอดตรงกว่ากัน

## ขั้นตอนที่ 5 — สลับใช้จริง

ถ้าโมเดลไทยดีกว่า: ปิด server ตัวเก่า แล้วรันตัวใหม่ที่พอร์ต 8000 ตามปกติ

```powershell
$env:STT_MODEL = "D:\models\typhoon-whisper-turbo-ct2"
python stt_server.py        # พอร์ต 8000 (ค่าอื่นมาจากค่าเริ่มต้น)
```

## ย้อนกลับ (ถ้าไม่ดี)

แค่ไม่ตั้ง `STT_MODEL` แล้วรันใหม่ → กลับไปใช้ `large-v3` ทันที

---

## สรุปสาเหตุ "ถอดไม่ตรง" เรียงตามน้ำหนัก

1. **โมเดล** — large-v3 ทั่วไป ยังเพี้ยนคำเชื่อมต่อ — แก้ด้วยโมเดลไทย ← คู่มือนี้
2. **เสียงเข้า** — ไมค์กล้องอยู่ไกล + ห้องมีเสียงรบกวน — แก้ด้วยพูดใกล้ 30-50 ซม., ปิดทีวี/พอดแคสต์
3. **ชื่อเฉพาะ** — แก้ด้วย hotwords ← ขั้นตอนที่ 0

> เกร็ด: อย่าตะโกนชิดไมค์ — เสียงจะแตก (peak > 0.8) ทำให้คำเพี้ยนเพิ่ม ไม่ใช่ดีขึ้น
