# อัปเดต STT Server — ให้ถอดเสียงไทย + ชื่อ "รีชชี่" แม่นขึ้น

> วันที่: 2026-09-16 · ไฟล์ที่อัปเดต: `server/stt_server.py`
> ใช้กับ: เครื่อง GPU (faster-whisper large-v3/CUDA) ที่ให้บริการ `http://<GPU_SERVER>:8000`

---

## 1) ปัญหาที่แก้

เวลาคนไทยพูดกับหุ่น คำที่ถอดออกมาเพี้ยนบ่อย โดยเฉพาะชื่อหุ่น และบางคลิปเสียงไม่ชัด
whisper จะเดาคำออกมาแปลก ๆ / หลุดเป็นอย่างอื่น เช่น

| ผู้ใช้พูด | ถอดได้ (แบบเก่า) |
|-----------|------------------|
| สวัสดีรีชชี่ | สวัสดี **ดีชิ้น** / **ริชิต** / **ลิเศษ** |
| ทำอะไรได้บ้าง รีชชี่ | ทำอะไรได้บ้าง **ลิชิก** |

สาเหตุหลัก: คลิปสั้น + เสียงระยะไกล ทำให้ whisper เดาศัพท์ผิด
(ตัว server บังคับ `language="th"` อยู่แล้ว — ไม่ใช่เรื่องภาษาไทยหาย)

---

## 2) สิ่งที่แก้ใน `server/stt_server.py`

| # | การแก้ | ผล |
|---|--------|-----|
| 1 | เพิ่ม `hotwords="รีชชี่ น้องรีชชี่"` | บังคับสะกดชื่อหุ่นถูก — **ทดสอบแล้วชนะขาด** |
| 2 | `condition_on_previous_text=False` | ลดอาการพูดวนซ้ำ ("โอเค โอเค โอเค โอเค") |
| 3 | `try/except TypeError` รอบคำสั่ง transcribe | faster-whisper เวอร์ชันเก่าที่ไม่รู้จัก `hotwords` → ถอดแบบเดิมอัตโนมัติ **ไม่ล่ม** |
| 4 | ตั้งค่าผ่าน env ได้ | ปรับได้โดยไม่ต้องแก้โค้ด (ดูตารางข้อ 5) |

---

## 3) ผลทดสอบก่อน/หลัง (ไฟล์เสียงจริงจากหุ่น)

ทดสอบด้วยโมเดลเล็ก (small) บนคลิปจริง 3 คลิป:

| คลิป | แบบเก่า (plain) | แบบใหม่ (hotwords) |
|------|------------------|---------------------|
| "ทำอะไรได้บ้าง รีชชี่" | `แล้วทำอะไรได้บ้าง ริชิต` | `ทำอะไรได้บ้าง รีชชี่` ✅ |
| "ฮัลโหล รีชชี่" | `เจ้าลิเศษ` | `รีชชี่` ✅ |
| (คลิปทักทาย) | `โอเค โอเค โอเค โอเค` | `รีชชี่` ✅ |

> หมายเหตุ: ฝั่ง server ใช้ large-v3 จะแม่นกว่านี้อีก — ผลนี้คือหลักฐานว่า `hotwords` ช่วยจริง

---

## 4) วิธีติดตั้งบนเครื่อง GPU

1. **ก๊อปไฟล์** `server/stt_server.py` (เวอร์ชันใหม่จากเครื่องหุ่น) ไปวางทับไฟล์เดิมบนเครื่อง GPU
   - วิธีไหนก็ได้: USB / แชร์โฟลเดอร์เครือข่าย / remote desktop
2. **ปิด server เดิม** — ไปที่หน้าต่างที่รัน server อยู่ แล้วกด `Ctrl+C`
3. **รันใหม่** ด้วยคำสั่งเดิมที่เคยใช้ เช่น

   ```powershell
   .venv\Scripts\python.exe stt_server.py
   ```

   (รอจนขึ้น `[STT] พร้อม model=large-v3 device=cuda` และ `[STT] listening :8000`)
4. **เช็คว่าserver ทำงาน** — เปิดในเบราว์เซอร์:

   ```
   http://<GPU_SERVER>:8000/health
   ```

   ต้องได้ประมาณ: `{"ok": true, "model": "large-v3", "device": "cuda"}`

---

## 5) ค่าที่ปรับได้ผ่าน environment variables (ถ้าต้องการ)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|--------|-------------|----------|
| `STT_MODEL` | `large-v3` | ชื่อโมเดล whisper |
| `STT_PORT` | `8000` | พอร์ตให้บริการ |
| `STT_LANGUAGE` | `th` | ภาษาที่บังคับถอด |
| `STT_HOTWORDS` | `รีชชี่ น้องรีชชี่` | คำบังคับศัพท์ (คั่นด้วยช่องว่าง) — เพิ่มคำอื่นได้ เช่นชื่อเด็ก ๆ ในห้อง |

ตัวอย่างรันพร้อมแก้ hotwords:

```powershell
$env:STT_HOTWORDS = "รีชชี่ น้องรีชชี่ อีฟ ครูปอ"
.venv\Scripts\python.exe stt_server.py
```

## 6) ทดสอบหลังติดตั้ง (ฝั่งหุ่น)

1. เปิดแอป: `.venv\Scripts\python.exe scripts\app_gui.py --hardware --camera lifecam --save-audio`
2. พูดว่า **"สวัสดีรีชชี่"**
3. ดู log ฝั่งหุ่น ต้องขึ้นประมาณ `🎤 ได้ยิน: 'สวัสดีรีชชี่'` (สะกดชื่อถูก)
4. ถ้าอยากตรวจซ้ำ ไฟล์เสียงถูกเก็บไว้ที่ `cache/stt_debug/HHMMSS.wav` — เปิดฟังได้

## 7) แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ/วิธีแก้ |
|-------|----------------|
| log ขึ้น `[STT] hotwords ไม่รองรับใน faster-whisper นี้` | เวอร์ชันเก่า → อัปเกรด: `pip install --upgrade faster-whisper` แล้วรีสตาร์ท server |
| ถอดได้ `''` (ว่าง) | คลิปนั้นไม่มีเสียงพูดจริง (เสียงรบกวน) → ไม่ใช่บั๊ก |
| ยังเพี้ยนบ่อย | พูดให้ใกล้ตัวหุ่นขึ้น (~1 คืบจากกล้อง) / ลดเสียงรบกวนในห้อง |
| `/health` ไม่ตอบ | server ยังไม่รัน / ไฟร์วอลล์ / port-forward 8000 หลุด |

## 8) พร้อมกันนี้ ฝั่งหุ่นก็มีการแก้ที่เกี่ยวข้อง (อัปเดตล่าสุด)

- **เลือกไมค์ถูกตัว**: MME index 1 (เสียงดังชัด) แทน DirectSound index 6 (เงียบ) แม้ config ใส่ชื่อไมค์เต็ม
- **เกณฑ์ตัดเสียง**: ปรับเพดานไม่เกิน 0.05 (เดิมเคยตั้งสูงถึง 0.08 จนเสียงพูดผ่านไม่ถึง)
- **ไมค์เปิดค้าง** (ContinuousMic): เก็บเสียงพูดได้ตลอด ไม่พลาดต้นประโยค
- **ติดตามใบหน้า**: checkbox "👀 ตามหน้า" ในแอป — หุ่นหันตามหน้าเรา
- **กัน USB หลุด**: แอปเช็คการเชื่อมต่อก่อนขยับ + watchdog ทุก 10 วิ
