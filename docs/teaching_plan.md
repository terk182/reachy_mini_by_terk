# 📚 แผนการสอน: หุ่นยนต์ + AI กับ Reachy Mini

> สอนเด็ก (อนุบาล–ประถม) โดยใช้หุ่นเป็นสื่อจริง — เรียงจากง่ายไปยาก
> แต่ละหัวข้อมี: แนวคิดหลัก / กิจกรรมกับหุ่น / คำถามชวนคิด

## บทที่ 1: หุ่นยนต์คืออะไร (อนุบาล)

- **แนวคิด**: หุ่นยนต์ = เครื่องที่ "รับรู้ → คิด → ทำ"
- **กิจกรรม**: พูด "สวัสดี" → หุ่นโบกมือ ; ชี้ส่วนประกอบให้เด็กดู
- **ชวนคิด**: "หุ่นกับของเล่นต่างกันยังไง?"

## บทที่ 2: หุ่นฟัง + พูด (ประถมต้น)

- **แนวคิด**: เสียง → ไมค์ → ข้อความ (STT) ; ข้อความ → เสียง (TTS)
- **กิจกรรม**: สั่งด้วยเสียง "ร้องเพลง" / "เต้น" ; ให้เด็กพูดช้าๆ ชัดๆ
- **ชวนคิด**: "ทำไมหุ่นต้องพูดช้าๆ ถึงฟังออก?"

## บทที่ 3: หุ่นขยับได้ยังไง (ประถมต้น-ปลาย)

- **แนวคิด**: มอเตอร์ = กล้ามเนื้อ, มุมองศา, ขา 6 ขาขยับพร้อมกัน
- **กิจกรรม**: `demo_show.py --scene move` ; สั่งโค้งคำนับ/ส่ายหัว
- **ชวนคิด**: "ถ้าอยากให้หุ่นยกมือ ต้องสั่งมอเตอร์ตัวไหน?"

## บทที่ 4: AI คิดยังไง (ประถมปลาย)

- **แนวคิด**: AI เรียนรู้จากข้อมูล, ตอบจากแบบแผนที่เรียนมา, ไม่มีความรู้สึกจริง
- **กิจกรรม**: ถามความรู้ "Square Root 2 เท่าไหร่" ; เล่านิทาน ; ดูว่าหุ่นตอบผิดเรื่องที่มันไม่รู้
- **ชวนคิด (สำคัญ)**: "หุ่นยนต์มีหัวใจไหม? เราเชื่อทุกอย่างที่ AI พูดได้ไหม?"

## บทที่ 5: หุ่นยนต์กับสังคม (ทุกวัย)

- **แนวคิด**: ใช้ AI อย่างปลอดภัย/รับผิดชอบ, งานที่หุ่นยนต์ช่วยคนได้
- **กิจกรรม**: ให้เด็กเสนอ "อยากให้หุ่นช่วยทำอะไร"
