📐 Reachy Mini DIY — ตำแหน่งมอเตอร์ + การเดินสาย STS3215

แผนผัง Servo ID 1–9 บนตัวหุ่น · กลไก Stewart crank-rod (arm 40 mm / rod 85 mm)

1. ตำแหน่ง Servo ID บนตัวหุ่น (มองจากด้านบน)

จานล่าง Stewart (มอเตอร์ 6 ตัวที่รัศมี 55 mm) + มอเตอร์ฐาน ID 7 (กลาง) + เสาอากาศ ID 8/9 (บนหัว)

2. ตารางสรุป Servo ID

IDชิ้นส่วนตำแหน่งทิศศอก (solution)
1ขา Stewartขวา (0°)0 (ปกติ)
2ขา Stewartหน้า-ขวา (60°)1 กลับด้าน
3ขา Stewartหน้า-ซ้าย (120°)0 (ปกติ)
4ขา Stewartซ้าย (180°)1 กลับด้าน
5ขา Stewartหลัง-ซ้าย (240°)0 (ปกติ)
6ขา Stewartหลัง-ขวา (300°)1 กลับด้าน
7หมุนตัว (base yaw)กึ่งกลางฐาน—
8เสาอากาศซ้ายบนหัว ฝั่งซ้าย—
9เสาอากาศขวาบนหัว ฝั่งขวา—
⚠️ ID 2, 4, 6 ต้องหันแขน (crank) กลับด้าน ตรงข้ามกับ 1, 3, 5 — ไม่งั้นแขนจะชนกันหรือทิศขยับผิด (ค่าจาก solution=[0,1,0,1,0,1])

3. การเดินสาย (half-duplex TTL)

ต่อ TX ตรง, RX ผ่านไดโอด, GND ร่วมทุกจุด, ไฟ 7.4V แยกจาก logic 5V

ขั้วสาย servo STS3215

สี (มาตรฐาน)ขาต่อกับ
🔴 แดงVCC+7.4V (LiPo)
⚫ ดำ/น้ำตาลGNDขั้วลบ 7.4V (GND ร่วม)
🟡 เหลือง/ขาวData (TTL)เส้นข้อมูล (รวมกันสายเดียว)

⚠️ สียืนยันกับ datasheet/สายจริงก่อน (Feetech บางรุ่นสีต่าง) · Baudrate = 1,000,000

4. ขั้นตอนหลังต่อสาย

  1. scripts/scan_servos.py — สแกนหา ID (ควรเจอ 1)
  2. scripts/set_servo_id.py --old 1 --new 2 — ตั้ง ID ทีละตัว (ตัวเดียวบนบัส)
  3. ตั้งให้ครบ: head=1–6, base=7, antennas=8,9
  4. scripts/test_servos.py 1 2 3 4 5 6 7 8 9 — ทดสอบ sweep
  5. scripts/calibrate.py --hardware — อ่านตำแหน่ง home จริง
