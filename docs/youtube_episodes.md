# 🎬 Reachy Mini — แผนทำ YouTube เป็นตอน ๆ

> ใช้หุ่น Reachy Mini DIY เป็นตัวเดินเรื่อง สอนเด็กเรื่องหุ่นยนต์ + AI
> แต่ละตอนสั้น 5-8 นาที (เหมาะกับเด็กสมาธิสั้น) — ถ่ายด้วย `scripts/demo_show.py` + ถาม-ตอบสด

## โครงสร้างซีรีส์: "น้องรีชชี่ เพื่อนหุ่นยนต์"

| Ep | ชื่อตอน | เนื้อหา | ใช้สคริปต์/ฟีเจอร์ |
|----|---------|---------|--------------------|
| 0 | **เปิดตัวน้องรีชชี่** | หุ่นคืออะไร, แนะนำตัว, โบกมือทักทาย | `demo_show.py --scene intro` |
| 1 | **หุ่นยนต์มีอะไรในตัว** | หู(ไมค์) ตา(กล้อง) สมอง(คอม) กล้ามเนื้อ(มอเตอร์) | `demo_show.py --scene parts` |
| 2 | **หุ่นขยับได้ยังไง** | มอเตอร์ STS3215 + แพลตฟอร์ม 6 ขา, โค้งคำนับ | `demo_show.py --scene move` |
| 3 | **หุ่นร้องเพลงได้ด้วย** | สังเคราะห์เมโลดี้ + เต้นตามจังหวะ | `demo_show.py --scene sing` |
| 4 | **หุ่นเต้นได้** | สั่งด้วยเสียง "เต้นให้ดูหน่อย" | `demo_show.py --scene dance` + voice_assistant |
| 5 | **หุ่นเล่านิทาน** | AI (LLM) สร้างเรื่องตามที่เด็กขอ | `demo_show.py --scene story` |
| 6 | **เล่นเกมทายเลขกับหุ่น** | บวกลบเลข, หุ่นฟังคำตอบแล้วชม | `game_math.py` |
| 7 | **เรียนภาษาอังกฤษกับหุ่น** | ท่องศัพท์, พูดตาม | `game_vocab.py` |
| 8 | **AI ฉลาดจริงไหม** | AI ตอบคำถาม, AI ไม่มีหัวใจจริง, ใช้อย่างปลอดภัย | voice_assistant ถาม-ตอบ |

## สคริปต์ตอนตัวอย่าง (Ep 1: หุ่นยนต์มีอะไรในตัว)

```
[เปิด] น้องรีชชี่ โบกมือ
🧒 พิธีกร: "น้องรีชชี่มีหูไหม?"
🤖 หุ่น: "มีครับ ผมฟังเสียงด้วยไมโครโฟนครับ" + เอียงหัว
🧒: "แล้วตาล่ะ?"
🤖: "ผมมีกล้องเป็นตาครับ" + มองซ้ายขวา
🧒: "สมองล่ะ?"
🤖: "สมองของผมคือคอมพิวเตอร์ครับ" 
🧒: "แล้วกล้ามเนื้อล่ะ?"
🤖: "กล้ามเนื้อผมคือมอเตอร์ 9 ตัวครับ ดูสิ" + เต้น
[ปิด] โค้งคำนับ + "แล้วเจอกันใหม่ครับ"
```

## เคล็ดลับถ่ายทำ

1. **มุมกล้อง 2 ตัว**: ตัวหน้าหุ่น (เห็นหน้า+ท่าทาง) + ตัวบน (เห็น servo ขยับ)
2. **ไฟสว่างพอ** ให้เห็นชิ้นส่วนกลไกชัด
3. **เสียง**: ใช้ไมค์ระยะใกล้ + ตัดเสียงรบกวน (หุ่นจะได้ยินคำสั่งชัด ไม่เพี้ยน)
4. **ซับไทย + ตัวการ์ตูนแทรก** อธิบายศัพท์ (ไมค์/กล้อง/มอเตอร์)
5. **โบนัสท้ายคลิป**: เบื้องหลัง "หุ่นรวน" — เด็กชอบดูของพัง+แก้

## รันก่อนถ่าย

```powershell
# ฉากเดียว (ถ่ายซ้ำได้)
.venv\Scripts\python.exe scripts\demo_show.py --hardware --scene sing

# โชว์ทั้งชุด
.venv\Scripts\python.exe scripts\demo_show.py --hardware

# ดูฉากทั้งหมด
.venv\Scripts\python.exe scripts\demo_show.py --list
```
